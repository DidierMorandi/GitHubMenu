GitHubMenu - Reference Manual

This manual summarizes the GitHub CLI commands used by GitHubMenu.

Main Commands

  • gh auth status: checks GitHub authentication.
  • gh repo view: reads information about the current GitHub repository.
  • gh repo view --web: opens the GitHub repository in the browser.
  • gh release create: publishes a new GitHub Release.
  • gh release download: downloads files from a Release.
  • gh release list: shows the Release history.
  • gh workflow list: lists GitHub Actions workflows.
  • gh run list: shows the latest workflow runs.
