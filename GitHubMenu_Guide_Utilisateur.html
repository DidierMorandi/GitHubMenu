GitHubMenu - Guide utilisateur

GitHubMenu permet d'utiliser GitHub CLI sans retenir les commandes par coeur.

Menu principal

  1. État GitHub : affiche l'authentification, le dépôt GitHub et les dernières versions.
  2. Publier une nouvelle version : crée une Release GitHub à partir d'un numéro de version.
  3. Télécharger une version : télécharge les fichiers d'une Release.
  4. Historique des versions : affiche les dernières Releases du dépôt.
  5. Ouvrir le dépôt GitHub : ouvre le dépôt dans le navigateur.
  6. Voir les workflows : affiche les workflows GitHub Actions et leurs dernières exécutions.
  7. Diagnostic GitHub : traduit les erreurs techniques en actions à réaliser.
  8. Outils avancés : donne accès aux commandes GitHub CLI moins fréquentes.
  9. Documentation du Père Claude : ouvre les manuels de l'outil.

Pré-requis

GitHub CLI doit être installé avec winget install GitHub.cli, puis configuré avec gh auth login.
