GitHubMenu - Guide utilisateur

Guide d'utilisation de l'interface graphique GitHubMenu pour piloter GitHub CLI sans retenir les commandes par coeur.

GitHub CLIReleasesWorkflows

Objectif

GitHubMenu aide a effectuer les operations GitHub les plus utiles depuis une fenetre unique : verifier l'etat d'un depot, publier une version, telecharger une release, consulter l'historique et ouvrir le depot dans le navigateur.

Demarrage

  1. Ouvrir GitHubMenu.
  2. Selectionner le depot local a traiter.
  3. Choisir une action dans le menu de gauche.
  4. Lire le resultat affiche dans la zone principale.

Menu principal

Etat GitHub

Affiche l'authentification GitHub, le depot courant et les informations principales renvoyees par GitHub CLI.

Publier une nouvelle version

Prepare la creation d'une release GitHub pour le depot selectionne, avec les fichiers et informations de version associes.

Historique et telechargement

Permet de consulter les releases existantes et de recuperer les fichiers publies pour une version.

Workflows

Affiche les workflows GitHub Actions et leurs dernieres executions afin de suivre les automatisations du depot.

Versions

Les actions liees aux releases reposent sur le depot GitHub associe au dossier local. GitHubMenu s'appuie sur les droits de l'utilisateur authentifie avec GitHub CLI.

Depannage

  • Si l'authentification manque, relancer la connexion GitHub CLI.
  • Si le depot n'est pas reconnu, verifier que le dossier choisi est bien un depot Git.
  • Si une release existe deja, choisir un autre numero de version ou consulter l'historique.
  • Si une commande echoue, lire le diagnostic affiche dans la zone de resultat.
