Overview

gh is GitHub's official command-line interface. It lets you perform GitHub operations — repositories, pull requests, issues, releases, workflows, and more — directly from the terminal, without using a browser.

gh <command> <subcommand> [flags]

All commands follow the same structure. Flags can be placed before or after arguments. Most read commands accept --json for machine-readable output, along with --jq / --template for filtering.

Installation

See the official instructions: https://github.com/cli/cli#installation

Supported platforms: Linux, macOS, Windows. Available via winget, brew, apt, dnf, conda, and direct binary download.

Check the installation:

gh --version

Authentication

gh auth login

Authenticate with GitHub. Prompts for the account type (GitHub.com or Enterprise), protocol (HTTPS or SSH), and preferred editor. Credentials are stored in the system keychain or in ~/.config/gh/hosts.yml.

gh auth login
gh auth login --hostname github.mycompany.com
gh auth login --with-token < token.txt

gh auth logout

Remove stored credentials for an account.

gh auth logout
gh auth logout --hostname github.mycompany.com

gh auth status

Display the current authentication status for all known hosts.

gh auth status

gh auth refresh

Refresh or extend OAuth token scopes for the current account.

gh auth refresh --scopes read:org,write:packages

gh auth setup-git

Configure git to use gh as its authentication helper.

gh auth setup-git

gh auth switch

Switch to another account when multiple accounts are authenticated.

gh auth switch

gh auth token

Print the authentication token for the current session (useful in scripts).

gh auth token

Global options

Flag Description
--version Print the gh version and exit
--help, -h Show help for any command

Exit codes

Code Meaning
0 Succès
1 Erreur générale
2 Usage error (incorrect flags, missing arguments)
4 Authentication required

Run gh help exit-codes for the reference list.

Environment variables

Variable Effect
GITHUB_TOKEN Token d'authentification ; remplace les identifiants stockés
GH_TOKEN Identique à GITHUB_TOKEN ; prioritaire
GH_HOST Hôte par défaut ; utile pour les environnements Enterprise
GH_ENTERPRISE_TOKEN Token for GitHub Enterprise scripts/automation
GH_REPO Override the repository context (owner/repo)
GH_EDITOR Éditeur lancé pour les saisies interactives
GH_BROWSER Navigateur utilisé par gh browse
GH_PAGER Pager utilisé pour les longues sorties (défaut : less)
NO_COLOR Désactiver la colorisation ANSI
CLICOLOR_FORCE Forcer la couleur même hors TTY

Run gh help environment for the complete list.

Configuration

gh config list

List all current configuration keys and values.

gh config get <key>

Read an individual configuration value.

gh config get editor

gh config set <key> <value>

Set a configuration value. Can be limited to a specific host with --host.

gh config set editor "code --wait"
gh config set git_protocol ssh
gh config set prompt disabled

Clés disponibles : editor, git_protocol (https/ssh), prompt (enabled/disabled), pager, http_unix_socket, browser.

gh config clear-cache

Vider le cache local des réponses HTTP.

Command reference

Main commands

gh repo

Manage GitHub repositories.

Subcommand Description
create Create a new repository (interactif ou avec flags)
clone <repo> Clone a repository locally
fork Fork the current repository or a specified repository
view [repo] View repository information
list [owner] List repositories for a user or organization
rename <new-name> Rename the current repository
edit Edit repository settings (description, visibility, topics...)
delete Delete a repository (confirmation required)
archive Archive a repository
unarchive Unarchive a repository
sync Sync a fork with its upstream
set-default [repo] Set the default repository for the current directory
deploy-key Manage deploy keys (add, delete, list)
autolink Manage autolink references (create, delete, list, view)
gitignore Parcourir et appliquer des modèles .gitignore (list, view)
license Parcourir les modèles de licence (list, view)

Examples:

gh repo create my-project --public --clone
gh repo clone owner/repo
gh repo view --web
gh repo fork --clone
gh repo sync

gh pr

Manage pull requests.

Subcommand Description
create Open a new pull request
list List repository pull requests
view [<numéro>] View a pull request
checkout <numéro> Check out a pull request branch locally
checks [<numéro>] Show CI checks for a pull request
diff [<numéro>] Show the diff for a pull request
merge [<numéro>] Merge a pull request
close [<numéro>] Close a pull request
reopen [<numéro>] Rouvrir une pull request fermée
edit [<numéro>] Edit metadata (title, body, labels, assignees...)
ready [<numéro>] Marquer une pull request draft comme prête pour la revue
review [<numéro>] Submit a review (approve, request changes, comment)
comment [<numéro>] Add a comment
lock [<numéro>] Lock the conversation
unlock [<numéro>] Déverrouiller la conversation
revert [<numéro>] Annuler une pull request fusionnée
status Show pull requests relevant to the current user
update-branch [<numéro>] Mettre à jour la branche avec la branche de base

Examples:

gh pr create --title "Fix login bug" --body "Fixes #42" --assignee @me
gh pr list --state open --label bug
gh pr checkout 321
gh pr merge 321 --squash --delete-branch
gh pr review 321 --approve

gh issue

Manage issues.

Subcommand Description
create Open a new issue
list List issues
view [<numéro>] View an issue
edit [<numéro>] Edit metadata
close [<numéro>] Close an issue
reopen [<numéro>] Rouvrir une issue fermée
comment [<numéro>] Add a comment
delete [<numéro>] Delete an issue (admin rights required)
develop [<numéro>] Create or list development branches linked to the issue
lock [<numéro>] Lock the conversation
unlock [<numéro>] Déverrouiller la conversation
pin [<numéro>] Épingler une issue
unpin [<numéro>] Désépingler une issue
transfer [<numéro>] <repo> Transfer an issue to another repository
status Show issues relevant to the current user

Examples:

gh issue create --title "Crash au démarrage" --label bug
gh issue list --assignee @me --state open
gh issue close 12 --comment "Corrigé dans #34"
gh issue develop 12 --name fix/startup-crash

gh release

Manage GitHub releases.

Subcommand Description
create <tag> Create a new release
list List releases
view [<tag>] View a release
edit <tag> Edit an existing release
delete <tag> Delete a release
download [<tag>] Download release assets
upload <tag> <fichiers> Upload assets to an existing release
delete-asset <tag> <asset> Delete a release asset
verify-asset Verify the integrity of a downloaded asset
verify Verify a release through attestation

Examples:

gh release create v1.2.0 --title "v1.2.0" --notes "Bug fixes" dist/*.exe
gh release list
gh release download v1.2.0 --pattern "*.exe"
gh release upload v1.2.0 build/MyApp.exe

gh gist

Manage GitHub Gists.

Subcommand Description
create [fichiers] Create a new gist
list List your gists
view [<id>] View a gist
edit [<id>] Edit a gist
clone <id> Clone a gist locally
rename <id> <old> <new> Rename a file in a gist
delete <id> Delete a gist

Examples:

gh gist create script.py --public --desc "Useful script"
gh gist list
gh gist view abc123 --raw

gh auth

Voir Authentication ci-dessus.

gh browse

Ouvrir une ressource GitHub dans le navigateur par défaut.

gh browse                    # repository home page
gh browse 42                 # issue or PR #42
gh browse --branch main      # branche spécifique
gh browse --commit abc1234   # commit spécifique
gh browse --repo owner/repo  # another repository

gh org

Subcommand Description
list List organizations the current user belongs to

gh project

Manage GitHub Projects (v2).

Subcommands : create, list, view, edit, close, delete, copy, link, unlink, mark-template, field-create, field-delete, field-list, item-add, item-archive, item-create, item-delete, item-edit, item-list.

gh project list
gh project create --owner @me --title "Sprint 12"
gh project item-add 1 --owner @me --url https://github.com/owner/repo/issues/42

gh codespace

Manage GitHub Codespaces.

Subcommands : create, list, view, edit, delete, stop, rebuild, code, ssh, cp, logs, ports, ports forward, ports visibility, jupyter.

gh codespace create --repo owner/repo --branch main
gh codespace list
gh codespace ssh

GitHub Actions commands

gh run

Manage workflow runs.

Subcommand Description
list List recent runs
view [<run-id>] Show run details and logs
watch [<run-id>] Suivre une exécution en temps réel
rerun [<run-id>] Relancer un workflow (ou seulement les jobs en échec)
cancel [<run-id>] Cancel a running workflow
delete [<run-id>] Delete a run
download [<run-id>] Download artifacts from a run

Examples:

gh run list --workflow ci.yml
gh run view 1234567890 --log
gh run watch
gh run rerun 1234567890 --failed-only

gh workflow

Manage GitHub Actions workflow files.

Subcommand Description
list List workflow files
view [<workflow>] View a workflow file
run <workflow> Déclencher un workflow manuellement (workflow_dispatch)
enable <workflow> Enable a workflow
disable <workflow> Désactiver un workflow

Examples:

gh workflow list
gh workflow run ci.yml --ref main
gh workflow run deploy.yml --field environment=production

gh cache

Manage Actions cache entries.

Subcommand Description
list List cache entries
delete <id> Delete a cache entry 
gh cache list
gh cache delete 12345

Additional commands

gh alias

Create and manage command shortcuts.

gh alias set pv 'pr view'
gh alias set issues 'issue list --assignee @me'
gh alias list
gh alias delete pv
gh alias import < aliases.yml

gh api

Make authenticated HTTP requests to the GitHub API (REST or GraphQL).

# REST {#rest}
gh api repos/owner/repo
gh api -X POST repos/owner/repo/issues --field title="Bug" --field body="Détails"

# GraphQL {#graphql}
gh api graphql -f query='{ viewer { login } }'

# Pagination {#pagination}
gh api repos/owner/repo/issues --paginate

Supports --jq for filtering and --template for Go template formatting.

gh search

Search GitHub from the command line.

Subcommand Description
repos Search repositories
issues Search issues
prs Search pull requests
commits Search commits
code Search code 
gh search repos "scanner réseau" --language php --stars ">100"
gh search issues "login bug" --repo owner/repo --state open
gh search code "WScript.Shell" --language vbscript

gh secret

Manage Actions secrets.

gh secret set MY_SECRET
gh secret set MY_SECRET --body "value"
gh secret list
gh secret delete MY_SECRET

Flags de portée : --repo, --org, --env.

gh variable

Manage Actions variables.

gh variable set APP_ENV --body "production"
gh variable get APP_ENV
gh variable list
gh variable delete APP_ENV

gh label

Manage repository labels.

gh label list
gh label create bug --color CC0000 --description "Something does not work"
gh label edit bug --name "Bug" --color EE0000
gh label delete bug
gh label clone owner/depot-source   # copy all labels from another repository

gh extension

Manage gh extensions (third-party subcommands).

gh extension search
gh extension browse
gh extension install owner/gh-ext-name
gh extension list
gh extension upgrade gh-ext-name
gh extension remove gh-ext-name
gh extension create my-extension
gh extension exec my-extension

gh copilot

Interact with GitHub Copilot from the CLI (Copilot subscription required).

gh copilot suggest "how to squash commits"
gh copilot explain "git rebase -i HEAD~3"

gh attestation

Manage artifact attestations (supply chain security).

gh attestation verify artifact.tar.gz --owner myorg
gh attestation download artifact.tar.gz --owner myorg
gh attestation trusted-root

gh ruleset

Inspect rulesets for a repository or organization.

gh ruleset list
gh ruleset view 12
gh ruleset check main

gh gpg-key

Manage GPG keys associated with the GitHub account.

gh gpg-key list
gh gpg-key add key.gpg
gh gpg-key delete <key-id>

gh ssh-key

Manage SSH keys associated with the GitHub account.

gh ssh-key list

gh ssh-key delete <key-id>

gh status

Show a dashboard of pull requests, issues, and review requests relevant to the current user across all repositories.

gh status

List available open source license identifiers.

gh licenses

Subcommands : install, preview, publish, search, update.

gh agent-task

Manage Copilot agent tasks (preview feature).

Subcommands : create, list, view.

Output formatting

Most list and view commands accept:

Flag Description
--json <champs> Sortie JSON en sélectionnant des champs spécifiques
--jq <expression> Filter JSON output with a jq expression
--template <chaîne> Format the output with a Go template 
gh pr list --json number,title,state
gh pr list --json number,title --jq '.[].title'
gh issue list --template '{{range .}}{{.number}}: {{.title}}{{"\n"}}{{end}}'

Run gh help formatting for details on available template functions.

GitHub Enterprise

# Authenticate to an Enterprise instance
gh auth login --hostname github.mycompany.com

# Set the default host for all commands
export GH_HOST=github.mycompany.com

# Scripts / automation
export GH_ENTERPRISE_TOKEN=<token>

Supporté à partir de GitHub Enterprise Server 2.20.
