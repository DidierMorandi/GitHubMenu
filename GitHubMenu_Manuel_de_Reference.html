GitHubMenu - Manuel de référence

Ce manuel récapitule les commandes GitHub CLI utilisées par GitHubMenu.

Commandes principales

  • gh auth status : vérifie l'authentification GitHub.
  • gh repo view : lit les informations du dépôt GitHub courant.
  • gh repo view --web : ouvre le dépôt GitHub dans le navigateur.
  • gh release create : publie une nouvelle Release GitHub.
  • gh release download : télécharge les fichiers d'une Release.
  • gh release list : affiche l'historique des Releases.
  • gh workflow list : liste les workflows GitHub Actions.
  • gh run list : affiche les dernières exécutions des workflows.

Source officielle

La référence complète est disponible sur https://cli.github.com/manual/.
