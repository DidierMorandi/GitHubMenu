GitHubMenu - Manuel de référence

Référence descriptive de l'interface graphique qui simplifie l'utilisation de GitHub CLI pour les dépôts DTL.

Type : application TkinterLangage : PythonVersion code : v1.0-6

Rôle

GitHubMenu fournit une couche graphique au-dessus de gh, l'outil officiel GitHub CLI. Il présente les actions GitHub courantes sous forme de menu numéroté, affiche les résultats dans une zone de sortie et aide à comprendre les erreurs renvoyées par GitHub.

Interface

Fenêtre principale

L'application affiche un en-tête, un bouton de sélection de dépôt local, une colonne d'actions et une zone de résultat. Le style reprend l'esprit terminal de la suite DTL avec fond sombre, texte vert et boutons sobres.

Dépôt courant

Le dépôt local sélectionné sert de contexte aux commandes GitHub CLI. Les opérations sont exécutées dans ce dossier afin de lire ou publier les informations du projet courant.

Domaines de commandes

DomaineDescription
État GitHubVérification de l'authentification, du dépôt distant et des informations GitHub visibles.
DépôtCréation ou ouverture du dépôt GitHub associé au projet local.
ReleasesPublication, téléchargement et consultation de l'historique des versions.
WorkflowsLecture des workflows GitHub Actions et des dernières exécutions.
Outils avancésAccès aux opérations GitHub CLI moins fréquentes, conservées dans une zone séparée.

Diagnostic

Le module de diagnostic traduit les messages techniques les plus courants en explications lisibles. Il distingue notamment les problèmes d'authentification, de dépôt absent, de droits insuffisants, de release déjà existante et de connectivité.

Documentation associée

GitHubMenu peut ouvrir les documents locaux ou publiés de la suite. Les documents de référence GitHub CLI restent disponibles sur le site officiel cli.github.com/manual.

Limites

  • GitHubMenu dépend de GitHub CLI installé localement.
  • L'application ne remplace pas toutes les options avancées de gh.
  • Les actions disponibles dépendent des droits GitHub de l'utilisateur authentifié.
